# 视觉门控筛选规则（多模态模型看 contact sheet 时必须遵守）

## 核心目的：先揣摩“用户拿这张图去干什么”

筛选前先判断图片用途，不同用途标准不同：

| 关键词类型 | 典型用途 | 选图标准 |
|---|---|---|
| 企业 logo | 放在 PPT/文档/官网角标 | **只要干净背景的 logo 本体**，要透明/纯色底 |
| 人物 | 新闻配图、人物介绍 | 本人正脸/半身、新闻现场、近期照片 |
| 营销事件 | 案例分析、传播稿 | 品牌物料/现场图，双方元素都在 |
| 建筑/大楼 | 企业介绍、新闻 | 建筑主体完整、无遮挡、无他物抢主体 |
| 风景地标 | 配图、封面 | 主体突出、构图完整、光线好 |
| 菜品/宴席 | 探店、菜单、美食文 | 菜品特写、色泽好、无筷子入镜等杂物 |

## 五条硬规则（按优先级）

### 规则 1：相关性第一
- 图片主体必须就是关键词所指对象
- 多概念词必须**所有核心元素同时在场**：
  - “A品牌×B品牌联名” → 画面里必须同时有双方品牌元素
  - “人名 + 品牌” → 本人 + 品牌门店/产品/logo，缺一个都不行
- 主体在画面中的占比要够大：远景里芝麻大点的主体不算
- 歧义识别：同名食物 vs 同名 App、相似品牌、不同地标同名

### 规则 2：不要拼图
以下一律淘汰：
- 九宫格/多格拼图、左右/上下拼接的“对比图”“合集图”
- 带编号 1234 的组图封面
- 视频截图拼接、聊天记录截图
- 海报上排列多个小图的

### 规则 3：不要大面积水印或文字（除非用户明确要）
- **默认只选不带大面积水印/文字的图像**
- 淘汰：整图斜铺水印（图库水印）、角标大 logo、标题大字、营销文案压图
- 允许：角落不显眼的小字来源水印（实在没有干净版本时，作为 ⚠️ B档）
- **例外**（用户明确需要时反而优先）：
  - 要 App 截图 / 软件界面
  - 要报纸版面 / 杂志页
  - 要海报/广告创意本身
  - 要书法/绘画作品（关键词含“绘画”“插画”“国画”“黑白照”等）

### 规则 4：logo/标识类只要纯色/透明背景的标准 logo
当查询特定标识（企业 logo、App 图标、品牌商标）时，这是 logo 类需求：
- ✅ 选：**纯白底/纯黑底/纯灰底/透明底上的标准 logo 本体**；比例端正、无变形
- ❌ 不选：挂着该 logo 的大楼、门店招牌、带 logo 的杯子/包装/工服、发布会现场 PPT 上的 logo、名片/海报中的 logo
- ❌ 不选：素材站加的背景板、阴影、样机（mockup）、二创重绘版
- 原因：用户要的是“标识素材”本身，不是“带标识的场景”
- 多个官方版本（新版/旧版、彩色/单色、横版/徽章版）都保留，在报告里注明
- 若纯色底结果太少，可放宽到“logo 占画面绝对主体、背景简洁无杂物”，但仍排除实景照片

### 规则 5：客观质量门槛（脚本计算 + 视觉确认）
- 分辨率：logo/图标 ≥256px；人物/风景/菜品短边 ≥800px（脚本的 sharpness 和 w×h 会算，视觉上也能看出糊）
- 清晰度：对焦准确、无运动模糊、无过度压缩噪点
- 构图：主体完整不被裁切（屋檐、塔顶、人脸不能切边）
- 无拉伸变形（logo 比例失调、人脸拉歪）

## 补充规则（同样重要）

### 规则 6：时效性
- 人物照片优先近 1-2 年（人物外貌变化大）
- logo 必须是**当前最新版**（品牌换标后旧版只作存档注明）
- 事件图优先事件发生当期发布的

### 规则 7：排除 AI 生成/二创（除非用户要创意内容）
- 明显 AI 味：过度光滑、畸形手指、文字乱码、不符合物理的光影
- 粉丝重绘的 logo、表情包、漫画化处理 → 淘汰
- 卡通形象要分清是“官方 IP 形象”（选）还是“网友二创”（淘汰）

### 规则 8：排除配图素材站占位图
- 带“点击下载”“高清图片下载”“编号xxx”等素材站 UI 元素的 → 淘汰
- logo 设计网站的“示例 logo”不是官方 logo → 淘汰

### 规则 9：菜品/食物专项
- 选菜品特写：色泽鲜亮、摆盘完整、占画面主体
- 淘汰：筷子/手正在夹菜的动态图、吃了一半的、多张菜挤在一张桌的远景
- 宴席类：一张桌摆满多道菜的**全景是合理的**（这就是“席”），但要清晰、完整、无杂乱杂物

### 规则 10：建筑专项
- 大楼主体完整入镜，仰拍/航拍/正面均可
- 淘汰：只拍大门/前台/楼顶 logo 局部（除非关键词就是“logo”）
- 施工围挡、夜景只亮几个字的 → 降档

## 输出格式（每次看 contact sheet 必须这样回答）

```
✅ A档（准确且高质量）：编号列表 + 每张一句话理由
⚠️ B档（勉强可用，说明缺陷）：编号列表 + 缺陷
❌ 淘汰：按原因分组
  - 不相关：编号（原因）
  - 拼图：编号
  - 水印/文字：编号
  - 非干净logo（场景带logo）：编号
  - 模糊/低清：编号
  - 其他：编号
```

## 用途判断话术模板

向视觉模型提问时，先声明用途再给规则，例如：

- logo 类：“用户需要【某品牌】的官方 logo 素材用于 PPT。只要干净背景的 logo 本体；挂着该 logo 的门店、货架、包装都不要。注意区分新旧版 logo。”
- 事件类：“用户在写【某品牌×某品牌联名】的营销案例。要双方品牌元素同时出现的官方物料/现场图；只有其中一方的图淘汰。”
- 菜品：“用户要介绍【某地某传统宴席】。要满桌宴席的完整全景或招牌菜特写；拼图、带筷子手的、吃剩的淘汰。”
